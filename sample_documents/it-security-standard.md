# IT Security Standard (Confidential)

## Laptop Security
All company laptops must use full-disk encryption and lock automatically after 5 minutes of inactivity. Operating system updates must be installed within 14 days of release.

## Passwords and MFA
Passwords must be at least 14 characters. Multi-factor authentication is mandatory for email, VPN and all cloud administration consoles.

## Incident Reporting
Suspected security incidents must be reported to security@northwind.example within 1 hour of discovery. The on-call security lead is reachable at extension 4400.

## Data Classification
Data is classified as Public, Internal, Confidential or Restricted. Restricted data may only be stored in approved encrypted systems and must never be sent by personal email.
